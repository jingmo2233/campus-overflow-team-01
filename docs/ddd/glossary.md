# 统一语言术语表 v1.0 (Ubiquitous Language)

本术语表用于规范 CampusOverflow 团队在业务沟通、数据库设计、代码编写过程中的命名。所有团队成员必须遵循此表中的英文命名。

| 中文术语 | 英文代码命名 | 业务定义/说明 | 所属上下文 |
| :--- | :--- | :--- | :--- |
| 问题 | Question | 用户发起的求助帖，包含标题和正文。 | 问答上下文 |
| 回答 | Answer | 针对某个问题的解答内容。 | 问答上下文 |
| 采纳 | Accept | 提问者将某个回答标记为“最佳答案”的动作。 | 问答上下文 |
| 投票 | Vote | 用户对问题或回答的赞同(Upvote)或反对(Downvote)。 | 互动上下文 |
| 声誉 | Reputation | 用户在社区中通过贡献积累的分数。 | 声誉上下文 |
| 标签 | Tag | 用于分类问题的关键词。 | 发现上下文 |
| 学号 | Student ID | 学生的唯一身份标识。 | 身份上下文 |
| 评论 | Comment | 对问题或回答的简短回复。 | 互动上下文 |
| 通知 | Notification | 系统推送给用户的消息（如被采纳、被回复）。 | 通知上下文 |
| 用户 | User | 系统的注册使用者。 | 身份上下文 |
| 管理员 | Admin | 拥有系统管理权限的用户。 | 身份上下文 |
| 教师 | Teacher | 拥有课程管理权限的特殊用户。 | 身份上下文 |
| 学生 | Student | 普通提问/回答的用户。 | 身份上下文 |
| 点赞 | Upvote | 支持某个内容的正向投票行为。 | 互动上下文 |
| 踩 | Downvote | 反对某个内容的负向投票行为。 | 互动上下文 |
| 排行榜 | Leaderboard | 按声誉分排序的用户列表。 | 声誉上下文 |
| 搜索 | Search | 根据关键词查找内容的动作。 | 发现上下文 |
| 过滤 | Filter | 根据标签或条件筛选内容。 | 发现上下文 |
| 违规 | Violation | 内容或行为违反了社区规定。 | 审核上下文 |
| 举报 | Report | 用户向管理员报告违规内容的行为。 | 审核上下文 |
| 删帖 | Delete Post | 将违规或错误的问题/回答下架。 | 问答/审核上下文 |
| 编辑 | Edit | 修改已发布的内容（有时间限制）。 | 问答上下文 |
| 匿名 | Anonymous | 隐藏真实身份发布内容。 | 身份上下文 |
| 悬赏 | Bounty | 提问者为了吸引回答而提供的声誉奖励。 | 问答上下文 |
| 金币 | Coin | 系统内的虚拟货币（可后续扩展）。 | 声誉上下文 |
| 徽章 | Badge | 达成特定成就后获得的标志。 | 声誉上下文 |
| 浏览 | View | 打开并查看问题详情的动作。 | 发现上下文 |
| 阅读量 | View Count | 问题被查看的累计次数。 | 发现上下文 |
| 认证 | Authenticate | 确认用户身份的过程（登录）。 | 身份上下文 |
| 授权 | Authorize | 确认用户是否有权限执行某操作。 | 身份上下文 |
