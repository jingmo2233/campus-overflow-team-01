### 可运行增量

- **注册 / 登录**：学号 + 密码（8–64 位，含字母与数字），服务端会话（Redis）+ CSRF 双提交；
- **课程**：课程列表、我的课程、加入课程；前端新增 `/courses` 页面，提问页可选择已加入课程；

- **渐进式质量门禁**（ADR-010）：S0 范围 = 共享内核 + Identity + Q&A（domain/application），

- **Product Backlog v2.0**：48 个 PBI（Issue #30～#77），S0=13、S1=43、S2=42、S3=31、S4=26 点。
- **文档**：`docs/ddd/`（上下文映射、事件目录、聚合、统一语言）、`docs/notes/architecture.md`、

## 升级 / 启动

```bash
# 中间件（3306 被占用时）
DB_HOST_PORT=3307 docker compose -f deploy/docker-compose.yml up -d mysql redis

# 后端（dev profile）
cd backend
DB_PORT=3307 mvn spring-boot:run -pl co-bootstrap -Dspring-boot.run.profiles=dev

# 前端
cd frontend && npm install && npm run dev
```

- Swagger：http://localhost:8080/swagger-ui.html
- 前端：http://localhost:5173
- 冒烟脚本：`http/auth.http`
